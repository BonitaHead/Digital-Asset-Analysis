# Case Studies

This directory will contain completed, evidence-based digital-asset investigations and analytical studies.

## Case Study Standard

Every completed study should contain:

1. **Research Question**
2. **Scope and Data Sources**
3. **Methodology**
4. **Observed Evidence**
5. **Analysis**
6. **Risk / Compliance Relevance**
7. **Limitations**
8. **Sources and Retrieval Dates**

### Evidence Language

Use precise language such as **observed**, **consistent with**, **may indicate**, **requires additional evidence**, and **not established by the available data**. Avoid presenting an analytical indicator as proof of identity, intent, or criminal conduct.
