# Transaction Research

This section contains transaction-level blockchain research using publicly observable ledger data.

## Current Case Study

- [Case Study 01 — Bitcoin Transaction Reconstruction](../case-studies/bitcoin-transaction-reconstruction.md)

## Analytical Workflow

**Research Question → Data/Evidence → Reconstruction → Pattern Analysis → Risk Interpretation → Limitations → Sources**

The objective is to demonstrate how blockchain transactions can be reconstructed and analyzed without overstating what on-chain evidence can establish about identity, intent, or illicit activity.
